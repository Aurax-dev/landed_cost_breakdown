Landed Cost Breakdown

Cancel a posted landed cost in one click — no mirror document, no negative landed cost. Tag every landed cost by component, and see exactly how each product's cost was built, down to the receipt it came from.

✦ One-Click Cancel ✦ Cost Components ✦ Printable Cost Sheet ✦ Cost Lock ✦ FIFO & AVCO

Standard Odoo will not let you cancel a validated landed cost — it tells you to post a negative one instead, leaving two documents in the ledger for one mistake. Landed Cost Breakdown adds a real Cancel button that voids the landed cost in place, cancels its journal entry, and rolls the stock valuation and product cost back — then shows you, component by component, how the cost you are left with was actually built.

Everything your costing needs

Eight capabilities on top of standard Odoo valuation — in one lightweight module.

❌

Cancel a Posted Landed Cost

One button on the landed cost form. It cancels the journal entry that was posted, marks the document Cancelled, and re-values the receipts it was loaded onto — so the stock valuation and product cost drop straight back. No reversing entry, no mirror document.
🏷️

Landed Cost Components

Tag every landed cost line as Freight / Landed, Duty / Tax, Direct Labour, Direct Other or Overhead. The tag follows the cost all the way through to the product cost breakdown, so management accounting questions have a real answer.
📋

Product Cost Sheet

A dated, versioned sheet per product showing purchase cost plus each landed component, per unit, reconciled against the product's actual cost. Every line links back to the purchase order or landed cost it came from.
✅

"Did the Landed Cost Apply?"

A live Landed Cost / Unit figure on the product tells you how much landed cost has actually been posted to it. The question every buyer asks after a shipment, answered without opening a single valuation report.
📈

Cost History per Receipt

One row per past receipt — date, document, quantity, base cost, landed cost and the resulting batch cost per unit. Filter by this month, last quarter, this year or a custom range to see how a product's cost moved.
🧮

How the Cost Is Calculated

A tab that lists the units still in stock layer by layer, each layer's unit cost and value, so the weighted average that makes up the current cost is laid out in front of you rather than inferred.
🔒

Cost Lock & Controlled Release

Switch on Lock Product Cost and the Cost field goes read-only for everyone. A Cost Manager releases a cost sheet to write its total back to the product — logged with who released it and when.
🖨️

Accountant-Ready PDF

Print any cost sheet as a QWeb PDF — the full component breakdown, the total, the product's current cost and the variance between them. Hand it to your accountant or file it with the month-end pack.

Up and running in minutes

No configuration project — install it and your existing landed costs already make sense.

1
 Install and pick your Cost Managers

Grant the Cost Manager group to whoever is allowed to release a cost back to a product. Everyone else can read cost sheets without changing anything.
2
 Tag your landed cost lines

On any landed cost, set the Cost Component on each line — Freight, Duty, Labour, Other or Overhead. Validate as usual; nothing about standard behaviour changes.
3
 Got one wrong? Press Cancel

Open the posted landed cost and click Cancel. The journal entry is cancelled, the document is stamped Cancelled, and the receipts it touched are re-valued — the product cost goes back to what it was.
4
 Open the Cost Breakdown on a product

Build a cost sheet and read the composition: purchase cost plus each landed component per unit, with the variance against the product's current cost.
5
 Lock the cost field

Turn on Lock Product Cost in Settings so nobody types over a costed product by hand. Changes then only happen through a released cost sheet.
6
 Print it for the accountant

Hit Print PDF on the cost sheet for a clean breakdown document — ready for month-end, an audit query, or a pricing discussion.
